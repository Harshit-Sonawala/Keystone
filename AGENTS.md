# Expo HAS CHANGED

Read the exact versioned docs at https://docs.expo.dev/versions/v56.0.0/ before writing any code.

# Typography Rule
Never use `font-extrabold` or `font-bold` in styling/typography unless explicitly specified by the user.
Never use `text-xs` in styling/typography unless explicitly specified by the user.

# Layout & Spacing Rule
Never use explicit one-off margin top (`mt-*`, `marginTop`) or margin bottom (`mb-*`, `marginBottom`) inline styles or utilities. Always use flexbox layout and gap spacing (`gap-*`, `gap-y-*`, flex alignment) instead.
